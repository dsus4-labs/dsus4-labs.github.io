The Failure Mode: Why n8n & Make Drop Ingestion Events

When third-party payment providers like Stripe or Shopify send webhooks, they enforce strict HTTP response timeouts (often 5 to 10 seconds). If your downstream n8n container is restarting, running an update, or handling a burst of 100 concurrent jobs, the webhook endpoint hangs. Stripe marks the webhook as failed, starts exponential retries, and eventually disables the webhook endpoint entirely.

Dead-Letter Queue CLI Management

If downstream services remain unreachable beyond maximum retry thresholds, payloads are moved to an immutable Dead-Letter Queue (DLQ). Operators inspect and replay events with single-key terminal commands:

# List DLQ items in formatted ANSI table
python webhook_vault.py dlq list

# Replay all failed events once downstream n8n is restored
python webhook_vault.py dlq replay --all
