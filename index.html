🛡️ Illegal State Traversal Gating

Unconstrained LLMs frequently execute tools out of sequence (e.g. running destructive shell commands before auth). Agent-FSM restricts tool visibility strictly to valid states in a formal directed graph.

🔄 Context Looping & Stagnation Breaker

When an LLM fails a tool invocation, it often enters an infinite retry loop with identical payloads. Agent-FSM hashes payloads via SHA-256 and trips the circuit automatically after 3 tries.

🧩 Zero-Cost Schema Validation Gate

Intercepts tool call arguments before execution. Malformed types or missing required fields are rejected at the gate without touching downstream tools or raising unhandled exceptions.

💾 Atomic SQLite Checkpoints & Recovery

Every state transition and execution latency is committed to an embedded SQLite database. Sudden process crashes can be resumed immediately with --session <id> --resume.
